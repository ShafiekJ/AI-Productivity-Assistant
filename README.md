# Flow State Assistant

Create a modern task management app with a clean, sleek design. Include features for an email generator,  meeting notes summarizer, task planner, research assistant and chatbot interface. Use a dark black and white color scheme.

the email generator should generate professional emails while taking input on the occasion and should support different tones.
The summarizer should summarize a given text and extract key notes, decisions, deadlines
The task planner should generate daily and weekly schedules which can be filled with a click as well as an adjustable priority list for each day
The research assistant should summarize articles when given a link and provide recommendations on similar topics or articles without being asked.
The workplace assistant should be interactive, speak warmly, handle user prompts and responses and be able to crack a joke occasionally
